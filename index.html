UKDSEAR

Explosive atmospheres. Two apps, one for the engineer and one for the person using equipment on site.

UKDSEAR ENGINEER Zone classification, equipment marking, the full L138 code of practice, check records and exports. UKDSEAR USER For people who use equipment on site. Pick the zone, read the plate, find out whether it is allowed in.
Install it on your phone
  1. Open the app you want above.
  2. iPhone: tap Share, then Add to Home Screen.
    Android: tap the menu, then Install app or Add to Home screen.
  3. It then opens full screen from your home screen, with no address bar, and works with no signal.
Why install rather than just visit Once installed the whole app is stored on the phone, so it opens instantly and works in a chamber with no reception. Visiting the page each time needs a connection the first time only, but installing is the reliable route.
